# T01 - Single Frame, 5-byte N-SDU

- **Phase / environment:** Phase 1, deterministic host fixture, 1 ms tick.
- **Config:** Data CAN ID `0x650`, FC CAN ID `0x658`, fixed DLC 8.
- **Input:** `00 01 02 03 04`.
- **Expected:** one SF `00 05 00 01 02 03 04 00`, no FC, READY payload
  length 5, one Tx `E_OK` and one Rx `E_OK`.
- **Actual frame:** `00 05 00 01 02 03 04 00` at tick 1; Data L-PDU 1.
- **Actual Tx:** 1 frame, 0 CTS, `CopyTxData=1`, Tx final count 1/result
  `E_OK`, committed offset 5.
- **Actual Rx:** 1 Data frame, 0 FC, `StartOfReception=1`, `CopyRxData=1`,
  Rx final count 1/result `E_OK`, length 5, payload `00..04` matched.
- **Actual queue:** READY count became 1 before final indication; final
  indication count became 1; consume returned length 5 and identical bytes.
- **Result:** **PASS**.

  [protocol_trace.log](raw/protocol_trace.log) and
